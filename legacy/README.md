# Old version (reference only)

These are the original scripts (`agent.py` menu, `run_auto.bat`,
`Merge_Claude_Output.bat` ...). They were replaced by v2 (`catprep.py` in the
project root) and are kept only for reference. They are not maintained.

`OLD_VERSION_DOCUMENTATION.md` describes how this old version works and lists
the problems that v2 fixes.

To run the old version anyway, copy these files back to the project root.
They expect `Data/`, `templates/` and the config next to `agent.py`.
